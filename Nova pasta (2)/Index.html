Sobre a Indieano Store

A Indieano Store nasceu como projeto de Desenvolvimento Front-End de Hyan Castro Nascimento e Guilherme Chagas. A ideia é aproximar o público de jogos feitos por estúdios pequenos, com uma vitrine simples e honesta.

Nossos compromissos

  • Descrições claras, sem exagero.
  • Preços visíveis antes de abrir o carrinho.
  • Dados do pedido validados apenas na página, sem envio a servidor.

Feito com

  • HTML5 semântico
  • CSS Grid e media queries
  • JavaScript puro e DOM
